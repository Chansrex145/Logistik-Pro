Listing 5.1 Potongan Kode Laravel Memproses Autentikasi dan Hak Akses Pengguna  
public function login(Request $request) 
    { 
 
        $credentials = $request->validate([ 
            'email' => 'required', 
            'password' => 'required' 
        ]); 
 
        if (Auth::attempt($credentials)) { 
 
            $request->session()->regenerate(); 
 
            if (Auth::user()->role == 'admin') { 
 
                return redirect('/dashboard'); 
            } elseif (Auth::user()->role == 'operator') { 
 
                return redirect('/operator/dashboard');

} elseif (Auth::user()->role == 'manager') { 
 
                return redirect() 
                    ->route('manager.order.report') 
                    ->with( 
                        'success', 
                        'Login Manager Berhasil' 
                    ); 
            } 
        } 
 
        return back()->with('error', 'Login gagal'); 
    } 
 
 
Potongan kode Laravel pada Listing 5.1 merupakan fungsi login yang digunakan untuk 
memproses autentikasi. Sistem akan memvalidasi email dan password pengguna. Apabila 
kredensial cocok, fungsi Auth::attempt akan mengembalikan nilai true dan sesi baru akan 
dibentuk melalui instruksi regenerate. Sistem kemudian mengevaluasi atribut role milik 
pengguna yang berhasil login. Pengguna dengan role admin diarahkan ke halaman dasbor utama, 
operator ke dasbor operator, dan manager ke halaman laporan pemesanan. Apabila login gagal, 
sistem akan mengembalikan pengguna ke halaman awal dengan pesan kesalahan.

5.2.4​Implementasi Algoritma Dijkstra 
Implementasi Algoritma Dijkstra menjadi fondasi komputasi Sistem Manajemen 
Transportasi dalam menentukan jalur pengiriman darat paling minimum. Modul rute ini 
menjelajahi ribuan kemungkinan ruas simpul jalan raya antara gudang logistik pemberangkatan 
awal dan pergudangan klien akhir. Logika Dijkstra mensubsidi efisiensi biaya, kecepatan 
perpindahan armada transportasi, serta optimalisasi usia pemakaian operasional armada secara 
otonom. 
Potongan kode PHP pada Listing 5.4 merupakan inisialisasi lingkungan pembentukan 
model graf awal Algoritma Dijkstra. Seluruh data jalan disalin dari basis data routes menuju 
arsitektur struktur array memori multidimensi $graph. Rancangan matriks tak berarah ini 
memastikan setiap jarak dari simpul asal diakomodasi sebaliknya secara sama panjang. Array 
$dist disiapkan untuk merekam perhitungan jarak minimum per simpul dan inisiasi penunjuk 
jalan dikosongkan menuju array $prev, seraya memastikan indeks simpul penelusuran masuk 
daftar antrean antarmuka variabel $queue.

Potongan kode PHP pada Listing 5.5 merupakan eksekusi tahap iterasi komputasi 
Dijkstra. Sepanjang tumpukan elemen matriks antrean masih melimpah, sistem memeriksa letak 
simpul persinggahan aktif $u yang mendekati titik terpendek. Proses dilewati apabila titik jarak 
berangsur bernilai tidak berujung (INF). Setelah dihapus dalam riwayat pemantauan, fungsi 
menelusuri rentang keseluruhan tetangga $v yang merelasi koneksi titik aktif $u. Logika 
kondisional menguji jarak rute jalan putar ($alt); dan bilamana ditemukan lintasan bernilai

agregat lebih kecil, maka nilai pembaruan disematkan menjadi acuan definitif perpindahan 
kendaraan logistik.
